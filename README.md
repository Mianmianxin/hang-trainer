# 小小悬挂侠 · 悬吊引体训练

一个给小朋友做**悬吊引体（单杠悬吊）**训练的网页 App。用语音对话启动倒计时，倒计时结束自动语音提醒，并以日历形式打卡，配合「我的世界」风格成就系统激励坚持。

> 纯前端单文件，无需后端、无需注册、不联网上传任何数据。

## 功能

- **语音对话启动**：说「开始」即起跳计时；说「下一组」跳过休息；说「停止」结束训练
- **多组训练**：每组时长 / 组数 / 组间休息可自由设置
- **语音倒计时提醒**：组次完成播报、最后 3 秒逐秒倒数、结束震动提醒
- **日历打卡**：月历视图打卡记录，统计连续打卡天数、本月打卡、累计悬吊秒数
- **成就系统**：12 个「我的世界」风格像素成就，每完成 5 次点亮一个（草方块 → 橡木 → 石镐 → 铁锭 → 金苹果 → 钻石 → 绿宝石 → 打火石 → 下界岩 → 女巫 → 末影龙蛋 → 末影龙）

## 使用方法

1. 用 iPad / iPhone 的 **Safari** 打开部署后的网址
2. 点击分享按钮 → **添加到主屏幕**，即可像 App 一样全屏使用
3. 首次开始训练时允许麦克风权限

## 部署到 GitHub Pages

1. 新建公开仓库（Public），上传本目录下的 `index.html`
2. 进入仓库 **Settings → Pages**
3. Source 选择 `Deploy from a branch`，Branch 选 `main`，目录选 `/ (root)`，点击 Save
4. 等待 1～2 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

## 注意事项

- **必须使用 https 访问**，否则 iOS 禁止调用麦克风（GitHub Pages 自动提供 https）
- 文件名必须为 `index.html`，否则首页无法打开
- 打卡数据保存在浏览器 localStorage 中，**仅存储在使用设备本地**，不会上传；清除浏览器数据会丢失记录
- iOS 上的语音识别支持因系统版本而异，若不支持语音启动，可使用页面的「说『开始』或点这里」按钮操作，语音播报功能不受影响
- 右上角 ⚙️ 可查看环境诊断（连接安全性、麦克风权限、语音支持情况）
